# 跑团模拟器

> 上下文编排器 + 规则引擎 + 状态机。灵感来自酒馆（SillyTavern），但补上了它最缺的一环：**权威的数值**。

## 当前进度：M0 地基完成 ✅

不依赖任何模型 API，核心引擎已可独立运行与测试。

```
npm test        # 37 个测试
npm run typecheck
npm run demo    # 跑一次没有模型的完整回合
```

## 已实现

### `src/core/dice` — 骰子引擎
- 表达式解析：`2d6+3` / `d20` / `d%`(=1d100) / `(1d4+1)*2` / `-1d6`
- **RNG 可注入**：`seededRng(seed)` 支持可复现掷骰，这是"重掷"和"回溯"的基础
- 分组记录每一组骰子，直接可用于骰点动画
- `distribution()` 完整枚举分布，用于公平性检验与期望值展示
- 已通过 10 万次 1d6 卡方检验（χ² < 15.09）

### `src/core/rulesets/coc7` — 克苏鲁的呼唤 第七版
- 成功等级：大成功 / 极难成功 / 困难成功 / 成功 / 失败 / 大失败
- 大失败规则：100 必失手；技能 < 50 时 96-99 亦为大失败
- 难度折算：困难 = 目标值/2，极难 = 目标值/5
- **奖励骰 / 惩罚骰**：额外掷十位骰取最小 / 最大，且相互抵消
- 百分骰细节：十位 00 + 个位 0 = 100

### `src/core/state` — 状态机（防数值漂移的核心）
- 模型只提交 `state_delta`（**变更意图**），数值全部由本地计算
- `amount` 可以是骰子表达式（如 `"1d6"`），由本地引擎掷
- 路径白名单：`vitals.*` / `inventory` / `flags.*` / `clues` / `location` / `npcsAlive`
- 规则包未定义的数值条一律拒绝（防模型凭空造出 `vitals.gold`）
- 数值自动裁剪到规则定义的 [min, max]
- **非法 delta 只拒绝、不抛异常** —— 一条离谱输出不会让整轮对话崩溃
- 不可变：`applyDeltas` 不修改传入状态

## 设计原则（后续开发必须遵守）

1. **随机与数值由本地引擎权威**。模型只写叙事，永远不参与算数
2. **事件日志是真相来源，摘要只是索引**
3. **规则可插拔**：引擎只依赖 `Ruleset` 接口，加 DND 5e 不需改引擎
4. **`core` 包纯函数、无 IO、可单测**
